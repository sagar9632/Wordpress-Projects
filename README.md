## About this repository

This repository is intended to showcase project documentation and screenshots. It is not a complete, ready-to-deploy backup of each live WordPress website. WordPress page content and Elementor layouts are commonly stored in the WordPress database, so a code-only repository may not reproduce the full website.

## Project evidence

Each project folder can contain:
- A short project overview
- The public live website URL
- Your actual role and contributions
- Screenshots captured from the project
- Any custom code that you own or have permission to share

## Privacy and licensing

- Never commit `wp-config.php`, passwords, API keys, `.env` files, or customer data.
- Do not upload client databases or SQL exports to a public repository.
- Only publish screenshots, source code, themes, plugins, and assets when you have permission.
- Do not redistribute premium themes or plugins unless their license allows it.
- A public website link is useful evidence, but it does not by itself prove authorship. Clearly describe your actual contribution.
